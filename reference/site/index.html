The model

Five decisions, and everything follows

01

Everything is a helper

A bare {{{city}}} calls the helper city — it is not a variable and not this.city. To read data you call lookup. There are no variables and no implicit context.

02

Juxtaposition applies, parens group

upcase (lookup this "n") is upcase of one argument. The parentheses group a sub-application — the Handlebars subexpression model, used uniformly. Not Lisp prefix.

03

No sugar in the core

Dotted paths, {{escaped}}, @index, ../x, as |x|, partials — all of it is an optional surface dialect that compiles down. The core only ever sees {{{ }}}.

04

Scope is just scoped helpers

A block like each installs temporary helpers (index, first, the item this) for its body, then removes them. No @-namespace, no context stack.

05

Value is pure data

A value is a string, number, bool, null, array, or object — never a function. Helpers live in a separate environment, so values stay serializable and comparable.

→

No built-ins. At all.

if each with esc_html — all userland. Delete them and the language still parses and runs. The prelude is the product you design.

Surface → core

The sugar is real, and it’s removable

Every familiar Handlebars construct is a pure rewrite to a smaller core form. Here are four, exactly as the specification’s appendix defines them — the contract is that no Handlebars concept is left unmapped.

 @data → scoped helpers
surface
{{#each people}}
  {{@index}}: {{this}}{{#if @first}} ★{{/if}}
{{/each}}

core
{{#each (lookup this "people")}}
  {{{(esc_html (index))}}}: {{{(esc_html this)}}}
  {{#if (first)}} ★{{/if}}
{{/each}}
 ../parent → explicit helper
surface
{{#with person}}
  {{firstname}} @ {{../company.name}}
{{/with}}

core
{{#with (lookup this "person")}}
  {{{(esc_html (lookup this "firstname"))}}} @
  {{{(esc_html (lookup (parent) "company" "name"))}}}
{{/with}}
 hash args → trailing dict
surface
{{> userBox person role="admin"}}

core
{{{ (partial "userBox" (lookup this "person")
           (dict "role" "admin")) }}}
 subexpressions → already core
surface
{{upper (concat first last)}}

core
{{{ (esc_html (upper
    (concat (lookup this "first")
            (lookup this "last")))) }}}
The mark

The triple-stash, stripped to bare rods

The core’s one and only inline output form is the triple stash, {{{ }}}. Strip its braces to their vertical strokes and you get seven bare rods. They dip to a valley in the middle — the empty slot between {{{ and }}}, the place a value goes. The centre rod is the value itself, in safety orange.

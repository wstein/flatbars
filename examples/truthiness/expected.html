FlatBars truthiness

The FlatBars column is computed live by the engine ({{#if v}}truthy{{else}}falsy{{/if}}). The Handlebars column is what Handlebars.js would decide for the same value. Rows marked ✗ diverge.

ValueFlatBarsHandlebarsParity

"hi" (non-empty string) truthy truthy ✓
"0" (string zero) truthy truthy ✓
" " (single space) truthy truthy ✓

42 (non-zero number) truthy truthy ✓

[1, 2] (non-empty array) truthy truthy ✓

(safe "") (empty trusted string) falsy truthy (a SafeString is an object) ✗ differs
(safe "x") (non-empty trusted string) truthy truthy ✓

The one number difference. FlatBars treats 0 as truthy. The full falsy set is false, null, "", the empty array, and a trusted empty string (safe ""); everything else, including 0 and {}, is truthy. Handlebars treats 0 as falsy unless includeZero is set. Guard zero explicitly where it matters, e.g. {{#if (not (eq n 0))}}…{{/if}}.

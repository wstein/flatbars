= 7. Host API
:navtitle: 7. Host API

The reference implementation is PureScript and compiles to JavaScript, so a FlatBars engine drops
into the same places {hb} does. This chapter sketches the surface a host uses; it is informative,
except for the AST and walk contract carried over from xref:evaluation.adoc[].

== 7.1 Pipeline

[source,text]
----
        PASS 1 — FlatBars core (structural only)      PASS 2 — the engine walk
String --lex--> [Token] --parse--> structural AST --walk: desugar + interpret--> output
----

Pass 1 is *purely structural*: the lexer and parser turn the source into a structural AST (the
skeleton) and stop. Pass 2 is the engine's *walk* over that tree — it is responsible for
*desugaring* (lowering the structural AST to the engine's real AST) *and* interpretation/validation.
Desugaring is therefore not a pre-parse front-end; it is a walker (`foldTemplate`) over the skeleton.

== 7.2 Types and functions

[source,haskell]
----
-- Pass 1: the structural parser (core)
parse        :: String -> Either ParseError Template          -- the structural (skeleton) AST

-- Pass 2: desugaring is a walk over the structural AST (a foldTemplate; see §A.13.2)
desugar      :: Template -> Template                          -- structural AST -> real AST

-- Phase 2: the polymorphic engine driver (FlatBars owns the walk; A.13)
runTemplate  :: forall m env. Monad m            => Engine m env -> Template -> m String
runString    :: forall m env. MonadThrow Error m => Engine m env -> String   -> m String

-- The reference engine, FullBars (one choice of m/env; Ch. 6), parametric in the monad
emptyEnv     :: forall m. Value -> RefEnv m
register     :: forall m. Ident -> Operation m (RefEnv m) -> RefEnv m -> RefEnv m
registerAll  :: forall m. Array (Tuple Ident (Operation m (RefEnv m))) -> RefEnv m -> RefEnv m
refEngine    :: forall m. MonadThrow Error m => RefEnv m -> Engine m (RefEnv m)
prelude      :: forall m. MonadThrow Error m => Array (Tuple Ident (Operation m (RefEnv m)))

-- Validation (the JSON-Schema-style pass) and analysis
validate     :: Schema -> Template -> Array Issue             -- schema = engine's contract
preludeSchema :: Schema                                       -- FullBars's schema (from FullBars)
foldTemplate :: Algebra a -> Template -> a                    -- catamorphism: prepare / analyze (A.13.2)
foldExpr     :: ExprAlgebra a -> Expr -> a                    -- catamorphism over an expression
splitClauses :: Template -> { before :: Template, clauses :: Array Clause }  -- all separator sections
splitClause  :: Ident -> Template -> { before :: Template, clause :: Maybe Template }  -- first of one name

-- Source spans (diagnostics): tag-level nodes and `Ctl` carry a `Span`
type Span    = { start :: Int, end :: Int }
spanText     :: String -> Span -> String                      -- the source text a span covers
lineColumn   :: String -> Int -> { line :: Int, column :: Int } -- 1-based, for an offset
-- Parse-error diagnostics (line/column, given the source)
parseErrorAt      :: String -> ParseError -> { line :: Int, column :: Int, offset :: Int, message :: String }
renderParseErrorAt :: String -> ParseError -> String          -- "line:column: message"

-- Convenience instantiations of the reference engine (from FullBars)
compile      :: String -> Either ParseError (Value -> Either Error String)   -- pure (m = Either Error)
renderWith   :: String -> Value -> Either String String                      -- pure, errors as text
renderAff    :: String -> Value -> Aff (Either Error String)                 -- async (m = ExceptT Error Aff)
-- Surface dialect (paths, {{ }} auto-escape, @data, else-if, partials; §5)
desugarSurface :: Template -> Template                                       -- surface ⇒ core rewrite
renderSurface  :: String -> Value -> Either String String                    -- parse + desugar + render
renderSurfaceWith :: Array (Tuple String String) -> String -> Value -> Either String String -- + named partials
-- Located parse errors at the host boundary (parse failures ⇒ "line:column: …")
renderWithDiag     :: String -> Value -> Either String String
renderSurfaceDiag  :: String -> Value -> Either String String
-- Host binding: render against native PureScript data (records, Array, Map, …)
toValue            :: forall a. ToValue a => a -> Value                       -- FlatBars.ToValue
renderValue        :: forall a. ToValue a => String -> a -> Either String String
renderSurfaceValue :: forall a. ToValue a => String -> a -> Either String String
----

The driver is *polymorphic in the monad `m` and the environment `env`* — the heart of the
inversion-of-control design (xref:appendix-handlebars.adoc#engine-api[A.13]). The reference engine
fixes `env = RefEnv m` and is supplied for `m = Either Error` (pure) and `m = ExceptT Error Aff`
(async); a different engine plugs in its own `env`/`resolve`/`stringify`.

`validate` is the JSON-Schema-style pass: walk the skeleton against an engine `Schema` and return
every unknown-helper / arity / block-misuse `Issue`, *before* rendering. A host may skip it (errors
surface lazily during the walk) or require it (strict). `preludeSchema` is the reference engine's
contract; `foldTemplate` is the catamorphism a custom analysis pass is built on.

== 7.3 Writing a helper

A helper is `Ctl m env -> Array Value -> m Value`. An inline helper ignores the control handle; a
block helper uses it. *FlatBars drives the walk and calls your helpers (inversion of control)* — the
helper recurses only by calling `ctl.render` / `ctl.clause`. Helpers are generic in `m`/`env`, so the
same code runs pure or async. See xref:appendix-handlebars.adoc#engine-api[A.13] for the full handle
(`runTemplate`, `runString`, `foldTemplate`).

[source,haskell]
----
-- upcase: a 1-argument inline helper (ignores the handle)
upcase :: forall m env. MonadThrow Error m => Operation m env
upcase _ args = case args of
  [v] -> VString <<< toUpper <$> stringify v
  _   -> throwError (ArityError "upcase/1")

-- if: a block helper that reads a nested `else` clause via the handle
ifHelper :: forall m env. MonadThrow Error m => Operation m env
ifHelper ctl args = case args of
  [cond] ->
    let { before, body } = ctl.clause "else"
    in if truthy cond
         then VSafe <$> ctl.render ctl.env before
         else VSafe <$> ctl.render ctl.env (fromMaybe [] body)
  _ -> throwError (ArityError "if/1")
----

== 7.4 {hbs} JavaScript API → FlatBars host API

[cols="2,2,3",options="header"]
|===
|{hb} |FlatBars |Note

|`Handlebars.compile(src)` |`compile src` |Surface in, `data -> String` out.
|`Handlebars.precompile(src)` |`parse` `>>>` `desugar` |Ship the desugared real AST; render later.
|`Handlebars.parse(src)` |`parse` |Returns the structural AST of xref:evaluation.adoc[].
|`Handlebars.registerHelper(n,f)` |`register n f` |`f` follows the `Operation` contract (the type formerly `Helper`; the host word stays *helper* — xref:concepts.adoc#glossary[glossary], xref:adr-0019-operation-vocabulary.adoc[ADR-019]).
|`Handlebars.registerPartial(n,t)` |`register n (partialOf t)` |A partial *is* a helper.
|`Handlebars.registerDecorator(n,f)` |`register n f` |Decorators are block helpers (xref:appendix-handlebars.adoc#decorators[A.8]).
|`options.fn` / `options.inverse` |`ctl.render` over `ctl.children` / over `ctl.clause "else"` |No inverse field; clauses are separator-delimited.
|`options.hash` |the trailing `dict` argument |xref:surface.adoc[] §5.4.

|===

== 7.5 Effectful and async hosts

Because the driver is polymorphic in `m`, an effectful host instantiates it at `m = ExceptT Error
Aff` — helpers and partials may then perform I/O (`liftEffect`/`liftAff`), and the result is
`Aff (Either Error String)`. `renderAff` is exactly this instantiation; the *same* prelude runs
unchanged. Pure hosts keep `m = Either Error` (`renderWith`) and pay nothing.

== 7.6 Host data binding

A host renders against a `Value`. Three ways to get one:

* *JSON wire data* — `FlatBars.Json.fromJson` (package `flatbars-json`) bridges an Argonaut `Json`.
This is an external adapter, kept out of the core (it pulls the JSON dependency).
* *Native PureScript data* — `FlatBars.ToValue.toValue` lowers records, `Array`, `Maybe`
(`Nothing ⇒ VNull`), string-keyed `Map`, and primitives into a `Value`; the record instance is
`RowToList`-driven, so each field is lifted by label into a `VObject`. It constructs only the core
`Value` and carries no engine meaning, so it lives in the core. The conveniences `renderValue` /
`renderSurfaceValue` are `renderWith` / `renderSurface` composed with `toValue` — e.g.
`renderSurfaceValue "<h1>{{ name }}</h1>" { name: "Ada" }`.
* *JavaScript hosts* — the `flatbars-js` facade (`FullBars.JS`, §A) exposes uncurried
`render(template, data)` / `renderSurface(template, data)` over plain JS values, returning a
`{ ok, value, error }` object; parse failures come back located (`line:column`).

The located-error renderers `renderWithDiag` / `renderSurfaceDiag` (and `formatError`) report a parse
failure as `line:column: message` (§7.2's `renderParseErrorAt`); the plain `renderWith` /
`renderSurface` keep the bare `show` form.

== 7.7 Engine conformance checklist

FlatBars is a substrate: "another engine may differ" recurs throughout
xref:adr-0001-structural-parser-and-walker.adoc[ADR-001],
xref:adr-0002-escaping-and-value-policy.adoc[ADR-002], and
xref:adr-0007-minbars.adoc[ADR-007]. For that to be testable rather than a slogan, a *conforming
engine* must declare each of the following. The reference engine (FullBars) is shown as the worked
example.

[cols="2,3,2",options="header"]
|===
| Must declare | Meaning | Reference (FullBars)

| *HTML-escape function*
| how text is made safe for HTML output
| `escapeHtml` — escapes `pass:[& < > " ']`, not backtick/`=` (shared; xref:adr-0002-escaping-and-value-policy.adoc[])

| *`stringify`*
| how a `Value` becomes output text (`Ctl.stringify :: Value -> m String`)
| `Kernel.Value.stringify`

| *Truthiness rule*
| the engine's `Truthy` callback (`Value -> Boolean`), seeded into the env — no falsy-set data, no `@truthiness` directive
| `handlebars` (FullBars), `nonEmpty` (RawBars/MaxBars), `mustache` (MinBars) — xref:adr-0022-analyse-mode.adoc[ADR-022]

| *Raw-output safety stance*
| does `pass:[{{{ }}}]` escape? is there a "you forgot to escape" lint?
| no auto-escape on `pass:[{{{ }}}]`; `escapingWarnings` lint, on-by-default in tooling

| *Admitted sigil/shape set*
| which tag shapes parse vs. raise `DisallowedShape` (the `extras` gate + any gated sigils)
| `extras = true` (raw blocks, `pass:[{{^}}]`, `pass:[{{&}}]`); no extra sigils

| *Grammar*
| the interior expression grammar plugged into `parseExpr`/`parseHead` (xref:adr-0004-token-lexer-and-grammar-seams.adoc[])
| the shared prefix grammar (`FlatBars.Expr`)

| *Real-AST shape, or "none"*
| the typed AST the engine lowers to, if it materializes one
| `RNode` via `Kernel.Lower.lower` — a *shared reference* lowering, mandated for no engine

| *Recursion stance*
| the render-recursion limit and its overflow behaviour
| _currently unbounded_ — see xref:adr-0012-recursion-budget.adoc[] (proposed)
|===

The last row is deliberately a known gap, not a checkmark.
